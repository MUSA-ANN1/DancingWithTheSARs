# Dancing with the SARs — Android App

A simple Android wrapper for the Dancing with the SARs website. It uses Android WebView to display the existing website in an app-style, full-screen interface.

## Features

- Loads the project website directly: https://musa-ann1.github.io/DancingWithTheSARs/
- Supports the website's JavaScript and local browser storage.
- Keeps project links inside the app and opens external links in the appropriate app or browser.
- Supports Android back navigation through WebView history.

The app is intentionally lightweight: the website provides the main interface and functionality, while the Android app provides the native container.

## Build

Open the project in Android Studio and run the `app` configuration on an Android device or emulator.

A debug APK is also included in this branch as `app-debug.apk`.
